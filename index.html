The Seven Pillars of CAIRN

The system architecture is strictly partitioned into seven deterministic pillars, cryptographically schema-enforced across all runtime nodes.

PILLAR EXECUTION PIPELINE FLOW Deterministic Sequence

Pillar Contract Enforcement

Schema Enforced
Pillar Key Responsibility Contract Enforcement Key Schema Fields
CAIRN Enterprise Trust & Security Gate Schema BLOCKING toolName, approved, riskLevel
PATH Workflow Intelligence & Router Advisory ADVISORY action, instruction
BEACON Operational Awareness & Telemetry Advisory ADVISORY message, status
COMPASS Governance & Audit Provenance Schema ADVISORY reasoningChain, governancePassed
ATLAS Knowledge Memory & Graph Advisory ADVISORY query, vectorMatches
FORGE Integration & Code Generator Schema BLOCKING code, language, crucibleResult
CRUCIBLE Isolated Execution Sandbox Schema BLOCKING sandboxed, method, assuranceTier

Enforcement Philosophy

  • BLOCKING Pillars (CAIRN, FORGE, CRUCIBLE): If a payload fails schema validation, execution is halted immediately (throwOnBlock = true). Unverified code or unvalidated execution results can never reach host storage or user context.
  • ADVISORY Pillars (PATH, BEACON, COMPASS, ATLAS): Contract defects do not stop execution, but surface mandatory warning blocks to the operator for complete operational disclosure.

THE 4-TIER CAIRN SYSTEM

The Cairn Architecture

The stacked cairn symbol represents the physical architecture: from user intent to cryptographic evidence.

Stone 1 (Top) • Ingress

1. Intent & Ingress Gate

Schema validation, AST parsing, and prompt injection filters before code touches any system.

Stone 2 • Governance

2. Policy & Governance Engine

Granular RBAC, egress IP whitelisting, and secret redaction enforced in microseconds.

Stone 3 • Execution

3. Dual-Runtime Sandbox

Dynamic hardware-isolated dispatch to Linux Docker or Windows Sandbox Hyper-V micro-VMs.

Stone 4 (Base) • Foundation

4. Cryptographic Evidence Ledger

Immutable SHA-256 decision records, SIEM audit streams, and EU AI Act compliance proofs.

Layered Trust Composition

Each layer builds deterministically upon the foundations below it. If any lower tier fails verification, execution halts immediately with zero side effects.
