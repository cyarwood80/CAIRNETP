HIGH-LEVEL ARCHITECTURE DECISION RECORDS (ADRS)

Architecture & Governance Summaries

High-level decision statements governing CAIRN's enterprise trust plane, dual-sandbox runtimes, and security boundaries.

ADR-0001: ACCEPTED

Default-Deny Security Choke Point

Problem: Unchecked AI model commands risk executing unauthorised operations on internal infrastructure.

Decision: Enforce a unified, default-deny security choke point prior to tool dispatch.

Outcome: Zero un-governed tool calls reach host operating systems.

ADR-0002: ACCEPTED

Sealed Contract Lifecycle

Problem: Vendor lock-in and cloud model outages threaten operational continuity.

Decision: Define sealed contract schemas separating model reasoning from execution state.

Outcome: Hot-swappable local and cloud model backings with zero code rewrites.

ADR-0003: ACCEPTED

Pre-Execution Syntax & Canary Probe

Problem: Unparseable scripts or missing dependencies pollute production environments.

Decision: Mandate pre-execution AST syntax checks and active toolchain canary probes.

Outcome: Unparseable scripts are transparently rejected before host touch.

ADR-0004: ACCEPTED

Dynamic Hardware Sensing & Allocation

Problem: Static model assignment causes hardware bottlenecks and latency spikes.

Decision: Dynamically sense local GPU VRAM and compute throughput in real-time.

Outcome: Optimal workload distribution across local hardware and cloud backends.

ADR-0005: ACCEPTED

Signed Decision Ledger Provenance

Problem: Lack of audit trails prevents regulatory compliance for AI-generated actions.

Decision: Log cryptographically signed SHA-256 decision chains for every turn.

Outcome: Tamper-evident, audit-ready decision lineage for enterprise risk teams.

ADR-0006: ACCEPTED

Honest Disclosure Guarantee

Problem: Over-claiming AI verification creates security blindspots and operational risk.

Decision: Enforce strict honest disclosure rules across all verification claims.

Outcome: Transparent disclosure of established runtime properties vs unverified states.

ADR-0007: ACCEPTED

Disposable Container Containment

Problem: Untrusted code execution poses container escape and host compromise risks.

Decision: Enforce disposable container containment with disabled networking and read-only mounts.

Outcome: Complete containment with zero host pollution or network egress.

ADR-0008: ACCEPTED

Tiered Verification Assurance Framework

Problem: Binary pass/fail checks fail to reflect complex enterprise verification levels.

Decision: Implement a 6-rung maturity ladder supporting dual Docker and Windows Sandbox VM runtimes.

Outcome: Explicit, progressive assurance tiers for administrative and enterprise tasks.

ADR-0009: ACCEPTED

Intent Verification & Outcome Assertion

Problem: Silent script failures cause unverified automated repair loops.

Decision: Require proof-of-completion assertions against contract criteria before task acceptance.

Outcome: Verifiable confirmation of intended business outcomes.

ADR-0010: ACCEPTED

Credential Denial Sentinel & Cost Metering

Problem: AI prompts and tool calls risk leaking sensitive credentials across network boundaries.

Decision: Deploy content-based payload evaluation that denies credentials automatically.

Outcome: Total secret leakage prevention even if models attempt exposure.

ADR-0012: ACCEPTED

Resolved Storage Standard & Path Masking

Problem: Unrestricted filesystem path references risk host directory traversal.

Decision: Standardise a single, verified storage resolution mechanism across all modules.

Outcome: Guaranteed environment isolation and host path protection.
