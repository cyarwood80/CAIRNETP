Architecting Trust for Agentic AI

Separating Intelligence from Governance through Architectural Control

By Chris Yarwood (@cyarwood80)

The foundational engineering text on securing autonomous agentic systems. As AI shifts from simple chatbots to autonomous actors with system access, traditional prompt-level guardrails fail. This book delivers the architectural blueprint for deterministic agent governance.

CAIRN ETP Repository

The Thesis of the Book

Why probabilistic LLMs must never be trusted to police their own system execution, and how physical architectural control solves agentic security.

The Agentic Security Trap

Prompt wrappers and system prompts are probabilistic recommendations, not security boundaries. Adversarial prompts can jailbreak soft instructions at execution time.

The Trust Fabric Pattern

Learn how to decouple reasoning intelligence from local hardware execution using an immutable, deterministic governance plane.

STRIX & COMPASS Protocols

Implement static AST red-teaming and cryptographically signed COMPASS evidence logs for full enterprise compliance.
